# IC-Design-Learning

A structured learning journey from digital circuits and RTL design to computer architecture and AI accelerators.

我是东南大学电子信息专业学生，正在结合大学课程学习数字 IC、计算机体系结构和 AI 加速器。这个仓库是长期工程学习档案：用可执行的任务、代码、实验和独立验收记录成长，基础课程成绩与理解深度优先。

## 从哪里开始

当前入口：**Stage 01 入阶段诊断 S01-M01-T01**，尚未开始。先按 [第一阶段计划](plans/stage-01-digital-circuits.md) 完成诊断，再按证据调整学习顺序；当前预计每周 6–8 小时，课程繁忙时可以减少或跨周。真实状态见 [PROGRESS](PROGRESS.md)，下一主阶段是矩阵乘法优化，但以阶段验收为准。

| 主线 | 核心目标 |
|---|---|
| 01 数字电路与 Verilog | 组合、时序、FSM、RTL 与自检仿真 |
| 02 C++ 矩阵乘法优化 | 正确性、访存、分块与性能实验 |
| 03 计算机组成与体系结构 | 数据通路、流水线、缓存、RISC-V |
| 04 AI 算法与计算特征 | GEMM、卷积、Attention、量化与瓶颈 |

| 06 数字 IC 设计流程 | 综合、STA、物理实现与 PPA |
| 07 完整 AI 加速器 | 分层验收的 MVP、Intermediate、Advanced |
